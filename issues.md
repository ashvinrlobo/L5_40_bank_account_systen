# Documented Issues in `bank_account_system.py`

| Issue | Type | Line(s) | Description | Fix Approach |
|---|---|---|---|---|
| Arbitrary Code Execution via `eval()` | Security (Bandit B307, Pylint W0123) | 39 | `eval(expr)` allows arbitrary code execution (RCE) on the host machine if malicious expressions are provided. | Replaced `eval()` with an AST-based safe expression parser (`ast.parse`) that only evaluates whitelisted arithmetic operators (`+`, `-`, `*`, `/`) and the `bal` variable. |
| OS Command Injection via `os.system()` | Security (Bandit B605, B607) | 55 | Calling `os.system("echo Backup complete: " + filename)` passes raw concatenated input to the system shell, enabling command injection via shell metacharacters and causing buffered output desynchronization. | Replaced `os.system` with Python's native `print(f"Backup complete: {filename}")` and removed the unused `os` module import. |
| Weak Cryptographic Hash (MD5) | Security (Bandit B324, B303) | 44 | Uses MD5 (`hashlib.md5`) for hashing customer PINs. MD5 is cryptographically broken and vulnerable to collision attacks. | Upgraded hash algorithm to SHA-256 (`hashlib.sha256(pin.encode()).hexdigest()`). |
| Insecure Pseudo-Random Number Generator | Security (Bandit B311) | 48 | `random.randint()` uses the Mersenne Twister PRNG, which is completely predictable and insecure for security-sensitive values like temporary PINs. | Replaced `random` with Python's cryptographically secure `secrets` module (`secrets.SystemRandom().randint(1000, 9999)`). |
| Mutable Default Argument | Bug / Code Quality (Pylint W0102, Flake8 B006) | 11 | `transactions=[]` is instantiated once when the function is defined, causing all accounts created with default transactions to share the same list instance and leak transaction histories. | Changed default parameter to `transactions=None` and instantiated a new list `transactions = []` inside the function body when `None`. |
| Bare `except:` Exception Handler | Code Quality / Reliability (Flake8 E722, Pylint W0702, Bandit B110) | 22-23 | Bare `except:` catches all exceptions, including `KeyboardInterrupt` and `SystemExit`, silently suppressing runtime issues. | Replaced the try-except-pass block with an explicit membership check (`if acc_id in account_data:`). |
| Unhandled File Resource Management | Reliability / Standards (Pylint R1732, W1514) | 52-54 | Using `open()` without a context manager (`with`) risks file descriptor leaks if exceptions occur before `f.close()`, and does not specify explicit encoding. | Replaced with `with open(filename, "w", encoding="utf-8") as f:`. |
| Dead Code / Unused Variable | Code Quality (Flake8 F841, Pylint W0612) | 27 | `service_fee = 2.50` is assigned in `withdraw()` but never deducted from account balance or referenced anywhere. | Removed the unused `service_fee` variable. |
| Non-idiomatic Comparison & Redundant `else` | Style / Code Quality (Flake8 E711, Pylint C0121, R1705) | 28, 32 | `account_data.get(acc_id) == None` violates PEP 8 (should be `is None`), and `else:` following an immediate `return` creates unnecessary indentation. | Simplified condition to `if acc_id not in account_data: return False` and removed the redundant `else:`. |
| Unused Import | Style / Quality (Flake8 F401, Pylint W0611) | 6 | `sys` is imported at module level but never used anywhere in the script. | Removed `import sys`. |
| Non-conforming Function Name | Style / Standards (Pylint C0103) | 11 | `createAccount` uses camelCase instead of PEP 8 snake_case. | Renamed function to `create_account` and provided a backward-compatible alias `createAccount = create_account`. |
| Missing Function & Module Docstrings | Code Quality / Standards (Pylint C0116) | 11, 19, 26, 43, 47, 51, 58 | Several functions lacked descriptive docstrings explaining their parameters and purpose. | Added descriptive docstrings to all functions and module level. |
| Missing Trailing Newline | Formatting (Flake8 W292, Pylint C0304) | 70 | File ended abruptly without a POSIX trailing newline. | Added a trailing newline character to the end of the file. |
